# Zombie Land #1

A three-act top-down zombie shooter for iPad, with touch sticks and a hardware keyboard.

You start with a pistol. A shotgun is lying in the lot. A machine gun is in the ward. Each act ends with a larger boss. Some zombies lose their heads. Blood stays on the concrete, but it does not take over the screen.

## Play

- Move: left stick, or WASD / arrow keys
- Aim and fire: right side of the screen, mouse, or hold Space
- Weapons: 1 pistol, 2 shotgun, 3 machine gun, once you have found them

Acts: The Lot, The Ward, The Morgue.
